# 🐜 개미증권 – 모의투자 게임

시드머니 1,000만원으로 시작해 👑 여의도 전설(100억)을 노리는 실시간 주식 게임입니다.
로그인, 저장, 랭킹, 멀티 모드는 구글 시트(Apps Script)를 서버로 씁니다.

## 게임 모드

- **🧍 솔로**: 혼자서 100억 도전. 일시정지·배속 가능, 서버에 저장되어 다른 기기에서 이어하기
- **👥 멀티 (최대 6명)**: 방 코드로 모여 같은 시장에서 대결 (3/5/7거래일)
  - 정해진 거래일이 끝났을 때 총 자산 1위가 우승
  - 📱 한 명당 찌라시 3장: 가짜 소문으로 시장 교란 (누가 뿌렸는지는 끝나고 공개)
  - 시장에도 찌라시가 돌아요 (60%는 가짜 → 팩트체크 후 되돌림)
- **📈 155개 종목**: 20개 업종(반도체·2차전지·바이오·방산·조선·원전·해운·화장품 등) 144종목 + ETF 11종 (레버리지·인버스2X·코스닥150 등)
- **🌍 세계 정세**: 전쟁·AI 붐·금리·감염병·환율·원전·물류대란 등 11가지 사건이 며칠에 걸쳐 단계별로 전개되며 여러 업종을 한 방에 움직여요
- **🎭 정보전**: 찌라시(가짜 뉴스), 오보 정정, 선반영(뉴스보다 가격이 먼저), 재료 소멸, 작전주(펌프 앤 덤프)
- **난이도**: 🌱 쉬움 / ⚖️ 보통 / 🔥 어려움 — 가짜 뉴스 비율, 선반영 빈도, 작전세력, 변동성, 반대매매 기준이 달라져요 (멀티는 방장이 선택)
- **💳 신용 (두 모드 공통)**: 자산의 최대 2.5배까지 투자. 담보비율 125% 미만이면 반대매매, 자산 0원 이하가 되면 **파산 = 패배**

## 파일 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 게임 전체 (GitHub Pages로 배포) |
| `Code.gs` | 구글 시트에 붙이는 서버 코드 (회원가입·로그인·저장·랭킹) |

## 1. 구글 시트 서버 만들기

1. [sheets.new](https://sheets.new)로 새 구글 시트를 만들고 이름을 정합니다. 예: `개미증권 DB`
2. 메뉴에서 **확장 프로그램 → Apps Script**를 엽니다.
3. 기본 코드를 전부 지우고 `Code.gs` 내용을 붙여넣은 뒤 저장(💾)합니다.
4. 오른쪽 위 **배포 → 새 배포**를 누릅니다.
   - 유형 선택(⚙️): **웹 앱**
   - 실행 사용자: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
5. **배포**를 누르고 권한 승인을 합니다.
   - "Google에서 확인하지 않은 앱" 화면이 나오면 **고급 → (안전하지 않음)으로 이동**을 누릅니다. 내가 만든 스크립트라 괜찮습니다.
6. 마지막 화면에 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.

> 첫 회원가입 때 시트에 `users` 탭이 자동으로 생깁니다.

## 2. 게임에 서버 주소 넣기

`index.html`에서 아래 줄을 찾아 따옴표 안에 1번에서 복사한 URL을 붙여넣습니다.

```js
const API_URL='';
```

## 3. GitHub Pages로 배포

1. GitHub 저장소에 `index.html`을 올립니다.
2. **Settings → Pages → Branch: main / (root) → Save**
3. 1~2분 뒤 `https://<아이디>.github.io/<저장소>/`에서 접속할 수 있습니다.

## 멀티 모드는 어떻게 동기화되나요?

- 방이 시작되면 서버가 **시드(난수 씨앗)**와 시작 시각을 정하고, 모든 참가자의 브라우저가 같은 시드로 같은 시장을 계산합니다. 그래서 서버는 실시간 시세를 보내지 않아도 됩니다.
- 서버(Apps Script)는 1.5초마다 참가자들의 총 자산, 파산 여부, 찌라시만 주고받습니다. 빠른 처리를 위해 CacheService를 쓰고, 방은 최대 6시간 유지됩니다.
- 찌라시는 서버가 "몇일차 몇 분"에 터질지 정하고 모두에게 같은 시점에 적용됩니다. 늦게 받은 참가자는 시장을 처음부터 다시 계산해서 맞춥니다.
- 끝난 게임 결과는 시트의 `matches` 탭에 기록됩니다.

## 서버 코드를 고쳤다면

Apps Script에서 **배포 → 배포 관리 → ✏️ 수정 → 버전: 새 버전 → 배포**를 해야 반영됩니다.
이렇게 하면 URL은 그대로 유지됩니다.

## 저장 방식

- 게임 상태는 이 기기(localStorage)와 서버(시트) 두 곳에 저장됩니다.
- 서버 저장은 1분마다, 장 마감 때, 그리고 앱을 닫거나 다른 탭으로 갈 때 이뤄집니다.
- 다른 기기에서 로그인하면 서버 저장본으로 이어서 할 수 있습니다. 이때 이전 기기는 자동으로 로그아웃됩니다.
- 시트 한 칸에 5만 자까지만 들어가기 때문에, 서버에는 압축본만 저장합니다. 장중 분봉은 복원할 때 다시 그려집니다.

## 알아둘 점

- 지금은 시세 계산이 각자의 브라우저에서 돌아갑니다. 그래서 개발자 도구로 자산을 조작해 랭킹에 올리는 것을 완전히 막을 수는 없습니다. 친구끼리 즐기는 용도로는 충분하지만, 상금을 걸 경우에는 시세 계산과 주문 체결을 서버로 옮겨야 합니다.
- Apps Script 무료 할당량은 소규모(수십 명) 사용에 충분합니다.
